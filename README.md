# Galarraga Eventos · Frontend Angular

Veja o README na raiz do pacote para iniciar a API Spring Boot com H2 e criar o administrador.

```sh
npm ci
npm start
```

O frontend abre em <http://localhost:4200>. As chamadas `/api` e `/auth` são encaminhadas à API local por `proxy.conf.json`. Use `npm run build` para compilar e `npm test -- --watch=false` para rodar os testes.
